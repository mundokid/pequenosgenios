PEQUENOS GÊNIOS — PÁGINA DE VENDAS PREMIUM
==========================================

ARQUIVOS
- index.html                  Página de vendas
- styles.css                  Visual responsivo
- script.js                   Botões de compra e visualizador das atividades
- assets/                     Imagens e capa otimizadas para celular
- amostra-gratis-3-atividades.pdf  PDF público com 3 atividades reais

1) CONECTAR O LINK DO CHECKOUT (OBRIGATÓRIO)
Abra script.js e substitua:
   const CHECKOUT_URL = 'COLE_AQUI_O_LINK_DO_CHECKOUT';
por exemplo:
   const CHECKOUT_URL = 'https://seu-checkout-aqui.com/pedido';
Use sua URL real. Todas as chamadas para compra passarão a usar esse destino.

2) PUBLICAR
Envie TODOS os arquivos e subpastas juntos para a hospedagem (Hostinger,
Netlify, Vercel, GitHub Pages etc.). A página é estática, sem necessidade de build.
Para ver localmente, abra index.html. A amostra em PDF e as imagens já funcionam.

3) PRODUTO COMPLETO
O PDF completo de 203 páginas NÃO foi colocado na pasta pública da página,
para evitar distribuir o arquivo pago. Faça upload do arquivo completo apenas
na área de entrega protegida da sua plataforma de vendas.

4) DEPOIMENTOS
Os três textos de professora, mãe e terapeuta estão identificados claramente
na página como EXEMPLOS FICTÍCIOS, não relatos de clientes reais.
Antes de anunciar como prova social, substitua por depoimentos verdadeiros,
com autorização de uso. Não apresente avaliações inventadas como autênticas.

5) PROMOÇÃO E EDIÇÃO
O desconto de R$47,90 para R$19,90 e a indicação por tempo limitado foram
configurados conforme solicitado. Não há cronômetro ou estoque falso.
A edição é apresentada como 2026/2027. Não há afirmação de validação clínica
ou certificação oficial de cada atividade.
